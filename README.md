# FotoDB 
[![License](https://img.shields.io/badge/license-GPLv3-blue.svg)](LICENSE)


FotoDB 是一款本地图片整理与检索 Android 应用。用户选择本机文件夹后，应用建立图片索引，可通过文件名、描述或标签搜索图片，并以网格或列表方式浏览。



</div>

## 功能

- **本地文件夹索引**：通过 Android 系统文件选择器添加一个或多个文件夹；递归扫描图片并保存索引。
- **搜索与浏览**：按文件名、图片描述和标签搜索；支持紧凑网格和缩略图列表两种视图。
- **图片信息管理**：为图片添加描述和逗号分隔的标签；可从应用索引中移除记录，不会删除原始图片。
- **端侧文字识别**：在单张图片编辑窗口中手动识别图片文字；OCR 结果可确认后填入描述并搜索。
- **图片查看**：全屏查看，支持双指缩放、双击缩放、拖动、旋转和适配屏幕。
- **分享图片**：通过 Android 分享面板将图片 URI 分享给其他应用。
- **缩略图缓存**：优先从内存缓存加载，再读取应用私有磁盘缓存；未命中时才从原图生成缩略图。
- **界面适配**：支持深色主题、屏幕刘海/打孔安全区域和软键盘调整。

## 使用方法

1. 启动应用，点击左上角菜单按钮打开侧边栏。
2. 选择“添加文件夹”，在系统文件选择器中选定图片所在目录并授权。
3. 等待扫描完成；扫描结果会显示图片数量和文件夹数量。
4. 使用顶部搜索框检索文件名、描述或标签。
5. 在侧边栏中切换网格/列表布局，或管理、刷新已添加的文件夹。
6. 点击图片打开信息编辑窗口；点击预览或“查看大图”进入全屏查看。
7. 打开单张图片的信息编辑窗口，点击“识别文字（端侧）”；检查识别结果，必要时选择替换或追加，再编辑并保存描述。

## 权限与数据

应用使用 Storage Access Framework 访问用户主动选择的目录，不需要广泛存储权限。目录读取授权会持久保存，便于下次启动继续访问。

图片原文件保持不变。图片索引、描述和标签存储在应用的 SQLite 数据库中；文件夹 URI 和显示模式存储在应用偏好设置中。缩略图缓存在应用私有缓存目录，Android 在存储空间不足时可能清除缓存，因此缓存不属于永久数据。
文字识别使用 Google ML Kit 端侧中文文本识别模型；项目打包对应模型，不会上传图片，不需要 OCR 网络服务或 API 密钥。识别只在用户手动触发单张图片时执行。输入图片会按最长边 3072 像素上限解码并应用 EXIF 方向；结果仅在用户保存编辑时写入描述。识别效果受原图清晰度、文字大小和排版影响。

移除文件夹会删除该目录对应的索引并释放授权；移除图片记录只影响索引。两种操作都不会删除原始图片文件。

## 构建

要求 Android Studio 和兼容项目配置的 Android SDK。项目使用 Gradle Kotlin DSL，应用模块为 `app`。

```bash
./gradlew :app:assembleDebug
```

安装到已连接设备：

```bash
./gradlew :app:installDebug
```

应用配置：

- Application ID：`com.hiople.fotodb`
- 最低 Android 版本：API 24
- Compile SDK：API 37
- Target SDK：API 37
- Java 语言级别：Java 11

## 项目结构

```text
app/src/main/java/com/hiople/fotodb/
├── MainActivity.java     # 界面、文件夹扫描、搜索、缓存、查看与分享
└── ImageDatabase.java    # SQLite 图片索引与描述/标签数据
```
